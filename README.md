Desearch is a search API for AI agents on Bittensor. Subnet 22 builds Desearch's web index, and Desearch runs the search API on top of it. It returns current, source-linked context from the web and X (Twitter). One API key covers AI Search, Web Search, Extract, and X Search, so an agent can search, read pages, pull X data, or get an answer grounded in the returned sources.

**Areas:** AI · Search · Web · API · Bittensor · Company
